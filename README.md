# Elementum – Agency Landing Page

A modern, responsive agency-style landing page built with **React**, **Vite**, **Tailwind CSS**, and **GSAP**. The project focuses on clean UI design, smooth animations, reusable components, and an engaging user experience across all devices.

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Modern agency-style user interface
* Smooth scroll-based animations using GSAP
* Reusable React component architecture
* Interactive sections and visual effects
* Optimized layout and typography
* Fast development workflow with Vite

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* GSAP (GreenSock Animation Platform)

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/nitaidalal/elementum-frontend-assignment.git
```

Navigate to the project directory:

```bash
cd elementum-frontend-assignment
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
